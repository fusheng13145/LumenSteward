## 1. 迭代 2 核心目标

**一句话**：在 MVP 链路基础上补齐五类业务意图端到端能力并完成"反幻觉基础版"，使"对外泄漏 = 0"具备可复现证据。

**关键结果 KR**：
- **KR1**：五类业务意图（图片识别 FR-10 / 语音生成 FR-11 / 快递 FR-12 / 导航 FR-13 / 宠物档案 FR-14）端到端可用，每类附 ≥1 组可执行证据（自动化测试 / 接口实测 / 日志片段）。
- **KR2**：执行性幻觉对外泄漏 = 0——构造"工具全部失败但模型声称成功"≥20 次场景，全部被拦截且留痕（呼应 FR-09 + QA-04 + BR-04）。
- **KR3**：工程门禁闭环——意图识别语料库 ≥300 条（FR-05 验收解锁）、CI 补齐 JaCoCo 覆盖率门禁（NFR-MA-04）与后端静态检查（NFR-MA-09），交付物须附证据（G1→BR-35）。

## 3. 优先级（MoSCoW）

> 依据 1.2.3：M=迭代1-2；S=迭代2-3；C=迭代4+。

| 优先级 | 迭代 2 工作项 | 可延后性 |
|---|---|---|
| **M（Must）** | FR-06、FR-10、FR-11、FR-12、FR-13 端到端打通；FR-09 执行一致性校验前移收尾；FR-14 贯通验证；TODO-05 语料库 ≥300 条；NFR-MA-04 覆盖率门禁；G1→BR-35 证据闸门（若 TODO-12 确认） | 不可延后——否则"五类意图端到端可用"交付判据不成立 |
| **S（Should）** | FR-16、FR-18；A-2 回放调试台；B-2 多模型可切换；NFR-MA-09 后端静态检查（Checkstyle/SpotBugs） | 可部分延后：A-2/B-2 与 NFR-MA-09 工期紧张时可后置到迭代 2 末或迭代 3 初，不影响 M 项交付判据 |
